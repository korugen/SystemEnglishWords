# シス単イメージ帳

『システム英単語』を横に置き、スマホでこのページを開いて、各単語の **イメージ（絵文字＋情景文）** を見ながら覚えるための非公式サイトです。

- 1単語ずつカード表示：番号・単語・品詞・絵文字のイメージ・情景の説明・意味
- 左右スワイプ / ◀▶ ボタンで前後へ、番号入力でジャンプ
- ☰ 一覧から検索（単語・番号・意味）
- 「意味を隠す」「英単語を隠す（イメージから思い出す）」モード
- 🔍 画像検索（Google 画像検索を開く）、✏️ 自分のイメージをメモ（端末に保存）
- 最後に見ていた位置を記憶

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を公開したいブランチ（例: `main`）の `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/SystemEnglishWords/` で開けます

ビルドは不要です（静的ファイルのみ）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | サイト本体 |
| `data/words.json` | 単語ごとのイメージデータ（見出し語・品詞・意味・絵文字・情景文） |
| `data/order.txt` | シス単の掲載順（`番号 見出し語` を1行ずつ） |

### `data/words.json` の形式

```json
{"w": "agree", "pos": "動", "ja": "同意する，賛成する", "em": "🤝👍", "img": "握手しながら笑顔でうなずき合う二人。"}
```

意味・情景文はすべてこのサイト用に独自に書いたもので、書籍の訳語や例文は転載していません。

### シス単の順番について

`data/order.txt` に `番号 見出し語` を書くと、その順番・番号で表示されます（熟語の見出しでも、含まれる主要語でイメージを探します）。
未登録のあいだはアルファベット順（番号は仮）で表示します。
スマホの ⚙設定 画面に貼り付けて保存することもできます（その端末だけに保存）。

> 書籍の単語の並び（番号付きリスト）を公開リポジトリに載せると、書籍の編集著作権に触れる可能性があります。
> 公開リポジトリで使う場合は、順番データは ⚙設定 から端末内にだけ保存する方法がおすすめです。
